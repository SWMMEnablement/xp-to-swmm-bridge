# XP to SWMM Bridge

XP to SWMM Bridge is a browser-based tool for converting legacy XPSWMM .xp model data into EPA SWMM5 .inp format. It includes conversion options and dry weather flow (DWF) extraction support, with a minimap for navigating the converted model. It is built with React, TypeScript, Vite, shadcn-ui, and Tailwind CSS.
